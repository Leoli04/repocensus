## 部署方式（无 gh CLI / 无 GITHUB_TOKEN 环境变量）
- 本机 git 走 Windows 凭据管理器可直推 `origin main`（github.com HTTPS 可达，api.github.com 也通）。
- 本地仓库状态混乱（origin/main 源码旧但数据新，本地分支基于旧 base）：采用「`git checkout -B main origin/main` 拉最新数据 + `git checkout <featurecommit> -- <源码目录>` 覆盖源码（不含 src/data）」重建干净的 main，再构建验证后推送。
